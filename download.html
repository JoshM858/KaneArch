Build from source
Produces a real, bootable Arch ISO via archiso.
Get the repo
$ git clone https://github.com/joshm858/kanearch.git
$ cd kanearch && sudo pacman -S --needed archiso
$ sudo ./build-orinsarch.sh

System Requirements

Build host
Arch Linux + archiso, root, several GB disk
RAM (live ISO)
2 GB recommended
CPU
x86_64
